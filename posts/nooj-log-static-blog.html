从零搭建 Nooj Log：一个极简静态博客的诞生

2026-10-05/10 min read/#博客#静态站点#工程实践

为什么最终没有选任何框架——以及这个用 HTML + CSS + 一点点 JS 手写出来的博客，是如何兼顾清爽与体感的。

动机#

折腾过太多博客系统：Hexo、Hugo、Notion 派生方案，每一个都很强大，每一个也都在「写一篇 800 字的随笔」和「跑一遍构建流水线」之间横亘着越来越长的距离。我想要的其实很简单：打开编辑器，写，保存，刷新，发布。

于是有了 Nooj Log——你现在看到的这个站点。零依赖、零构建、零追踪器，三个 HTML 加一份 CSS，一把 JS。

架构决策#

  • 形态：纯静态多页站点，不做 SPA。文章详情页通过 ?id= 从数据层读取，省掉构建步骤，也保留分享链接的能力。
  • 分层：数据层（data.js）与视图层（各页面 js）分离，新增文章只动数据文件，不动结构。
  • 设计系统：tokens.css 集中管理颜色、字阶、间距、动效，暗色模式只覆盖语义变量，组件零改动。

目录结构#

text
nooj-log/
├── index.html        # 首页：hero + 分类 + 最新文章 + 项目 + 近况
├── posts.html        # 文章归档：分类筛选 + 搜索
├── post.html         # 文章详情：目录 + 阅读进度 + 上下篇
├── projects.html     # 项目展示
├── about.html        # 关于
└── assets/
    ├── css/          # tokens / base / components 三层
    └── js/           # data / main / home / posts / post

设计上的几个取舍#

清爽不等于性冷淡。暖纸白的底、墨绿的主色、衬线的中文大标题，再让等宽字体去承担日期、标签、目录这些「开发者气质」的信息——这是「代码与生活」在视觉上的对位。

全站的母题是「迹」：hero 里点阵淡出、区块间的虚线分隔、线上的菱形结点、终端卡片里的 git 提交图，甚至列表符号都是菱形。slogan 里那个「迹」字，底下也压了一条点线下划。

部署#

整个目录传到任何静态托管（或一台 Nginx）上就完成了，域名指向 nooj.cn。没有 CI、没有 hook，git push 之后手动 sync，痛快。
